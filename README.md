# Matematica Greta

Webapp statica: non richiede installazione, compilazione o chiavi API.

## Pubblicazione su GitHub Pages
1. Estrarre questo ZIP.
2. Caricare tutti i file e le cartelle nella radice del repository: index.html deve essere nella radice.
3. Nel repository aprire Settings > Pages.
4. Selezionare Deploy from a branch, quindi il branch main e la cartella / (root), e salvare.
5. Aprire il collegamento indicato da GitHub Pages al termine della pubblicazione.

I collegamenti sono relativi e funzionano anche sotto il nome del repository.

## Accesso e dati
La protezione di accesso del precedente hosting Sites non è inclusa: questa copia non contiene autenticazione. Su un GitHub Pages pubblico chiunque può consultare app e PDF. Le autorizzazioni assegnate alle email in Sites non vengono trasferite.
Gli appunti e i progressi rimangono nel browser e nell'indirizzo dove sono stati creati; non vengono trasferiti automaticamente al nuovo sito.
Il file Excel originale e i nomi dei partecipanti non sono inclusi. I valori statistici usati negli esercizi sono inclusi nell'app.

## Aggiornamenti
Questa è una copia della versione esportata. Le modifiche pubblicate su Sites non aggiornano automaticamente GitHub Pages: occorre caricare i nuovi file.
